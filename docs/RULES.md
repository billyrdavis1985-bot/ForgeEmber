# Hackathon rules checklist (Meta Muse Ember Hackathon, Cerebral Valley)

Taken from the event brief. Tick each box before submitting.

## Window and budget
- [ ] Built between **Nov 23, 2026, 9:00 AM ET** and **Dec 2, 2026, 9:00 PM ET** (target: Dec 2, 3:00 PM ET)
- [ ] Total Meta Model API spend **≤ $10.00**. Over $10 means **disqualification.** Our code enforces **$9.00**.
- [ ] Meta's spend-limit alert is set up (it only emails; it does not stop usage)
- [ ] No Playground or Muse Code usage outside our ledger can quietly push total spend toward $10 (see META_API_NOTES §12–13)

## Model and tooling
- [ ] Built on **Muse Ember (`muse-ember-1.0`)** through the Meta Model API
- [ ] Muse Code used where it helps (encouraged); trajectory exported with `/export trajectory`

## Proof of usage
- [ ] Prompt/token trace showing Ember usage and amount spent (`traces/submission-trace.jsonl`, `traces/summary.json`)
- [ ] Usage-page screenshot for Nov 23–Dec 2, filtered to Muse Ember
- [ ] Muse Code trajectory JSON (if Muse Code was used)

## Team and originality
- [ ] **Solo:** Billy Davis is the only builder. AI assistants disclosed in the README.
- [ ] **New work only:** the demo shows only what was built during the event
- [ ] **No code from ForgeVigil** or any earlier project. The README says so.

## Openness and rights
- [ ] Repo is **public** and open source (**MIT**)
- [ ] Every dataset's license verified at its primary source (`docs/DATA.md`). Using data we don't have rights to means **disqualification**.
- [ ] No third-party code or assets without a compatible license

## Projects to avoid (none of these may be the main feature)
- [ ] Not a dashboard-first product (the approval console is secondary)
- [ ] No Streamlit
- [ ] Not a basic RAG app, plain image analyzer, education chatbot
- [ ] No mental-health/medical/nutrition advice, job screener, personality or sports analyzer

## Submission package
- [ ] 3-minute demo video
- [ ] Public repo link
- [ ] Project description
- [ ] Trace + usage screenshot + Muse Code trajectory

## Judging weights (for prioritizing)
Impact 30% · Use of Meta AI tooling 25% · Technical depth 20% · Demo 25%

Prizes targeted: **Best Frontier Build**, **Scale the Real World**.
