Risk specialist · verdict suspicious

The video shows a payee bank-detail change justified only by a phone call, a classic payment-diversion pattern requiring independent verification. No urgency, secrecy, or impersonation language is present, so this is suspicious rather than proven fraud.

Skeptic · argues benign

This shows a routine in-system edit to an existing payee, with the account name matching Marrowvale Couriers, a documented reason for the change, and a separate confirmation step before the update and the GBP 235.20 scheduled payment. There is no external email, urgency, secrecy, or new payee creation in the video, and the new sort code shares the 30 prefix with the old one, consistent with a supplier bank change.

What would change my mind: Call Marrowvale Couriers on a number already on file (not from the call that prompted the change) and obtain independent written confirmation of new sort code 30-94-12 and account 55018273; if they deny the change, this would no longer look benign.
